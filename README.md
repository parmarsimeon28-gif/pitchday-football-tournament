# Pitchday

A mobile-first football tournament app. No participant accounts or paid services required.

- Round robin (single leg or home and away) and knockout fixtures with byes.
- Enter scores and automatically update round robin standings: points, goal difference, then goals scored.
- Scores save in the organizer's browser. Share a read-only link snapshot; copy a fresh link after updates.
- Up to 32 teams. Static app, no build step.

## Deploy

Import this public GitHub repository in Vercel. Use the default static deployment settings; the app entry point is index.html.
